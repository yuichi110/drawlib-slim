アーキテクチャと PHP-FIG (PSR) 標準への準拠#

Slim v4.15.3 は全 72 ファイル（3,149 LOC）の 100% で declare(strict_types=1) を徹底し、独自の HTTP メッセージ実装や専用 DI コンテナを内包せず、PHP-FIG (PSR) 標準インターフェースに疎結合でバインドする設計を採用しています。

標準規格 Composer パッケージ バージョン制約 Slim v4.15.3 における役割
PHP ランタイム php, ext-json ~7.4.0 || ~8.0.0 .. ~8.5.0 厳格なスカラ型ヒント・戻り値型、および JSON ボディ解析・エラー出力。
PSR-3 psr/log ^1.1 || ^2.0 || ^3.0 ErrorMiddleware と ErrorHandler に注入される LoggerInterface（デフォルトは Slim\Logger）。
PSR-7 psr/http-message ^1.1 || ^2.0 ミドルウェアとルート間で授受されるイミュータブルな ServerRequestInterface、ResponseInterface、StreamInterface。
PSR-11 psr/container ^1.0 || ^2.0 AppFactory、CallableResolver、MiddlewareDispatcher が参照する任意の DI コンテナ ContainerInterface。
PSR-15 psr/http-server-handler, psr/http-server-middleware ^1.0 RequestHandlerInterface（App、Route、RouteRunner）および MiddlewareInterface（Slim\Middleware\*）。
PSR-17 psr/http-factory ^1.1 Psr17FactoryProvider により自動検出される ResponseFactoryInterface と StreamFactoryInterface。
ルーティング nikic/fast-route ^1.3 Dispatcher と FastRouteDispatcher がラップする高速正規表現ルータ。

packageSlim\#

ルートアプリケーションカーネル、Callable 解決、LIFO ミドルウェアディスパッチャ、レスポンス送出、ロガー — 詳細は 01. App & Factories を参照してください。

ルート名前空間 Slim\ には、PSR-15 リクエスト処理パイプラインの統括、文字列表記や DI コンテナからの Callable 解決、および SAPI クライアントへのレスポンス送出を担う 5 つの基幹クラスが定義されています。

シンボル 種別 継承 / 実装インターフェース 概要
Slim\App class extends RouteCollectorProxy, implements RequestHandlerInterface アプリケーション本体（VERSION = '4.15.1'）。ルート・ミドルウェア登録、handle() による実行、HEAD リクエスト時の空ボディ保証（RFC 2616）、run() による送出を担当。
Slim\CallableResolver final class implements AdvancedCallableResolverInterface クロージャ、Invokable オブジェクト、[class, method] 配列、'Class:method' 文字列を PSR-11 コンテナ検索または直接インスタンス化（new $class($container)）で解決。
Slim\MiddlewareDispatcher class implements MiddlewareDispatcherInterface 中心カーネル（RouteRunner）を匿名ハンドラフレームで同心円状に包む LIFO（後入れ先出し）PSR-15 ミドルウェアスタック。
Slim\ResponseEmitter class — PSR-7 ResponseInterface のヘッダ（複数 Set-Cookie 保護付き）、ステータス行、チャンク分割ボディ（既定 4096 バイト）を出力。
Slim\Logger class extends Psr\Log\AbstractLogger PHP 標準の error_log() へメッセージを出力する軽量な既定 PSR-3 ロガー。

packageSlim\Factory#

アプリケーションおよび ServerRequest の静的ブートストラップファクトリ — 詳細は 01. App & Factories を参照してください。

Slim\Factory 名前空間には、明示的な引数・PSR-11 コンテナ・PSR-17 自動検出を組み合わせて Slim\App と ServerRequestCreatorInterface を構築する 2 つの静的ファクトリクラスが用意されています。

シンボル 種別 概要
Slim\Factory\AppFactory class create()、createFromContainer()、determineResponseFactory()、およびコンテナや各種コンポーネントを事前設定する静的セッター群を提供。
Slim\Factory\ServerRequestCreatorFactory class PHP スーパーグローバル（$_SERVER, $_GET, $_POST, $_COOKIE, $_FILES）から ServerRequestInterface を生成する ServerRequestCreatorInterface を構築。

packageSlim\Factory\Psr17#

PSR-17 HTTP ファクトリ自動検出レジストリ & ベンダー別アダプタ群 — 詳細は 02. PSR-17 Providers を参照してください。

Slim\Factory\Psr17 名前空間の 10 クラスは、Composer でインストール済みの PSR-7 / PSR-17 実装を優先順（SlimPsr17Factory, HttpSoftPsr17Factory, NyholmPsr17Factory, LaminasDiactorosPsr17Factory, GuzzlePsr17Factory）に自動検出し、必要に応じて slim/http デコレータを適用します。

シンボル 種別 継承 / 実装インターフェース 対応 Composer パッケージ
Slim\Factory\Psr17\Psr17FactoryProvider class implements Psr17FactoryProviderInterface 検出対象 Psr17Factory クラス名の優先順位リストを管理（getFactories(), setFactories(), addFactory()）。
Slim\Factory\Psr17\Psr17Factory abstract class implements Psr17FactoryInterface class_exists() による存在確認と ResponseFactoryInterface、StreamFactoryInterface、ServerRequestCreator の生成を担う抽象基底クラス。
Slim\Factory\Psr17\ServerRequestCreator class implements ServerRequestCreatorInterface ベンダー別の生成クラスとメソッドを Closure::fromCallable() 経由で呼び出し、スーパーグローバルから ServerRequestInterface を生成。
Slim\Factory\Psr17\SlimHttpServerRequestCreator class implements ServerRequestCreatorInterface 内部の ServerRequestCreatorInterface が生成したリクエストを Slim\Http\ServerRequest（slim/http）でラップするデコレータ。
Slim\Factory\Psr17\SlimPsr17Factory class extends Psr17Factory slim/psr7（Slim\Psr7\Factory\ResponseFactory, StreamFactory, ServerRequestFactory::createFromGlobals）。
Slim\Factory\Psr17\SlimHttpPsr17Factory class extends Psr17Factory slim/http（Slim\Http\Factory\DecoratedResponseFactory によるレスポンスファクトリの装飾）。
Slim\Factory\Psr17\NyholmPsr17Factory class extends Psr17Factory nyholm/psr7 & nyholm/psr7-server（統合型 Nyholm\Psr7\Factory\Psr17Factory と ServerRequestCreator::fromGlobals）。
Slim\Factory\Psr17\GuzzlePsr17Factory class extends Psr17Factory guzzlehttp/psr7（GuzzleHttp\Psr7\HttpFactory, GuzzleHttp\Psr7\ServerRequest::fromGlobals）。
Slim\Factory\Psr17\LaminasDiactorosPsr17Factory class extends Psr17Factory laminas/laminas-diactoros（Laminas\Diactoros\ResponseFactory, StreamFactory, ServerRequestFactory::fromGlobals）。
Slim\Factory\Psr17\HttpSoftPsr17Factory class extends Psr17Factory httpsoft/http-message & httpsoft/http-server-request（HttpSoft\Message\ResponseFactory, StreamFactory, ServerRequestCreator::createFromGlobals）。

packageSlim\Routing#

ルート登録、ルートグループ、URL 逆引き生成、FastRoute ディスパッチ & ルート実行 — 詳細は 03. Routing Subsystem を参照してください。

Slim\Routing 名前空間の 11 クラスは、ルーティング DSL、ネスト可能なグループ、名前付きルートからの URL 生成（RouteParser）、FastRoute の正規表現ディスパッチとキャッシュ、リクエスト属性へのコンテキスト埋め込み（RouteContext）、およびルート単位のミドルウェア実行を担います。

シンボル 種別 継承 / 実装インターフェース 概要
Slim\Routing\RouteCollectorProxy class implements RouteCollectorProxyInterface get(), post(), put(), delete(), options(), patch(), any(), map(), group(), redirect() を備えるルーティングプロキシ（Slim\App の親クラス）。
Slim\Routing\RouteCollector class implements RouteCollectorInterface ルートとグループの登録管理、既定の呼び出し戦略、ベースパス、FastRoute キャッシュファイルを保持する中央レジストリ。
Slim\Routing\Route class implements RouteInterface, RequestHandlerInterface 単一ルートを表し、独自の MiddlewareDispatcher、ルートパラメータ、呼び出し戦略、グループチェインを保持。
Slim\Routing\RouteGroup class implements RouteGroupInterface 共通の URI プレフィックスとグループミドルウェア群を束ねて配下のルートへ適用。
Slim\Routing\RouteContext final class — RouteContext::fromRequest($request) でリクエスト属性から Route, RouteParser, RoutingResults, basePath を型安全に取得する値オブジェクト。
Slim\Routing\RouteParser class implements RouteParserInterface 名前付きルートとパラメータから relativeUrlFor(), urlFor(), fullUrlFor() を逆引き生成。
Slim\Routing\RouteResolver class implements RouteResolverInterface RouteCollectorInterface と DispatcherInterface を橋渡しし、RoutingResults の算出と RouteInterface の解決を実行。
Slim\Routing\RouteRunner class implements RequestHandlerInterface ミドルウェアスタックの最深部カーネル。未解決時のルーティング補完、RouteContext::ROUTE 属性の設定、Route::run() の呼び出しを実行。
Slim\Routing\Dispatcher class implements DispatcherInterface FastRoute の simpleDispatcher / cachedDispatcher を駆動し、RoutingResults と許可メソッド一覧を返却。
Slim\Routing\FastRouteDispatcher class extends FastRoute\Dispatcher\GroupCountBased HEAD -> GET 自動フォールバックと許可 HTTP メソッド抽出を備えるカスタム FastRoute ディスパッチャ。
Slim\Routing\RoutingResults class — ディスパッチ結果（NOT_FOUND = 0, FOUND = 1, METHOD_NOT_ALLOWED = 2）、ルート識別子、rawurldecode 済み引数、許可メソッドを保持。

packageSlim\Middleware#

組み込み PSR-15 サーバーミドルウェア群 — 詳細は 04. Built-in PSR-15 Middlewares を参照してください。

Slim\Middleware 名前空間には、ルーティング、例外捕捉、リクエストボディ解析、HTTP メソッド上書き、出力バッファリング、Content-Length 付与を担う 6 つの標準 PSR-15 ミドルウェアが揃っています。

シンボル 種別 実装インターフェース 概要
Slim\Middleware\RoutingMiddleware class MiddlewareInterface 後続ミドルウェアの実行前にルーティングを完了させてリクエスト属性を付与し、不一致時は 404 / 405 例外を送出。
Slim\Middleware\ErrorMiddleware class MiddlewareInterface 最外層の try / catch (Throwable) 境界として例外を捕捉し、型別のカスタムハンドラまたは既定の ErrorHandlerInterface に委譲。
Slim\Middleware\BodyParsingMiddleware class MiddlewareInterface application/json, application/x-www-form-urlencoded, application/xml（text/xml）のボディを解析し $request->withParsedBody() に設定。
Slim\Middleware\ContentLengthMiddleware class MiddlewareInterface レスポンスストリームのサイズ（$response->getBody()->getSize()）を計測し、Content-Length ヘッダを自動付与。
Slim\Middleware\MethodOverrideMiddleware class MiddlewareInterface X-Http-Method-Override ヘッダまたは POST ボディの _METHOD パラメータに基づきリクエストメソッドを上書き。
Slim\Middleware\OutputBufferingMiddleware class MiddlewareInterface ob_start() で標準出力を捕捉し、PSR-7 レスポンスボディの末尾（APPEND）または先頭（PREPEND）に結合。

packageSlim\Handlers#

標準 ErrorHandler とルート呼び出し戦略（Invocation Strategies） — 詳細は 05. Error Handler & Route Strategies を参照してください。

Slim\Handlers および Slim\Handlers\Strategies 名前空間には、コンテンツネゴシエーション対応の ErrorHandler と、ルートコールバックの引数渡し方式を切り替える 4 つの Strategy クラスが含まれています。

シンボル 種別 実装インターフェース コールバック呼び出しシグネチャ
Slim\Handlers\ErrorHandler class ErrorHandlerInterface Accept ヘッダから最適なエラーレンダラ（json, xml, html, text/plain）を選択し、PSR-3 ログ出力とエラー ResponseInterface 生成を実行。
Slim\Handlers\Strategies\RequestResponse class InvocationStrategyInterface 既定の戦略: function (ServerRequestInterface $request, ResponseInterface $response, array $args): ResponseInterface。
Slim\Handlers\Strategies\RequestResponseArgs class InvocationStrategyInterface ルート引数を位置引数として展開: function (ServerRequestInterface $request, ResponseInterface $response, string $arg1, ...): ResponseInterface。
Slim\Handlers\Strategies\RequestResponseNamedArgs class InvocationStrategyInterface ルート引数を PHP 8 名前付き引数として展開: function (ServerRequestInterface $request, ResponseInterface $response, string $id, ...): ResponseInterface。
Slim\Handlers\Strategies\RequestHandler class RequestHandlerInvocationStrategyInterface PSR-15 スタイル（function (ServerRequestInterface $request): ResponseInterface）で呼び出し、任意でルート引数をリクエスト属性に注入。

packageSlim\Error\Renderers#

Slim\Error および Slim\Error\Renderers 名前空間の 5 クラスは、捕捉された Throwable を $displayErrorDetails フラグおよび $exception->getPrevious() チェーンに従って各 MIME 形式の文字列へシリアライズします。

Slim\Error\Renderers\JsonErrorRenderer class extends AbstractErrorRenderer application/json, application/vnd.api+json（JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES）。
Slim\Error\Renderers\HtmlErrorRenderer class extends AbstractErrorRenderer text/html, application/xhtml+xml（htmlentities() エスケープ済み HTML テンプレート）。
