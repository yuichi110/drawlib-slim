Architecture & PSR Standards Compliance#

Slim v4.15.3 is architected around PHP-FIG (PSR) standards with declare(strict_types=1) enforced across 100% of its 72 source files (3,149 lines of code). Rather than bundling a monolithic HTTP message implementation or proprietary dependency injection container, Slim binds cleanly to any compliant PSR implementation:

Standard Composer Package Version Constraint Role in Slim v4.15.3
PHP Runtime php, ext-json ~7.4.0 || ~8.0.0 .. ~8.5.0 Strict scalar type hints, return types, and JSON error/body serialization.
PSR-3 psr/log ^1.1 || ^2.0 || ^3.0 LoggerInterface injected into ErrorMiddleware and ErrorHandler, with Slim\Logger as fallback.
PSR-7 psr/http-message ^1.1 || ^2.0 Immutable ServerRequestInterface, ResponseInterface, and StreamInterface flowing through every middleware and route.
PSR-11 psr/container ^1.0 || ^2.0 Optional ContainerInterface resolved by AppFactory, CallableResolver, and MiddlewareDispatcher.
PSR-15 psr/http-server-handler, psr/http-server-middleware ^1.0 RequestHandlerInterface (App, Route, RouteRunner) and MiddlewareInterface (Slim\Middleware\*).
PSR-17 psr/http-factory ^1.1 ResponseFactoryInterface and StreamFactoryInterface auto-discovered via Psr17FactoryProvider.
Routing Engine nikic/fast-route ^1.3 Regular-expression chunked route compiler wrapped by Dispatcher and FastRouteDispatcher.

packageSlim\#

Root Application Kernel, Callable Resolution, LIFO Middleware Dispatcher, Response Emitter & Logger — Detailed in 01. App & Factories.

The root Slim\ namespace houses the 5 foundational runtime classes that orchestrate the PSR-15 request handling pipeline, resolve string/container callables, and stream HTTP responses to the SAPI client:

Symbol Kind Implements / Extends Summary
Slim\App class extends RouteCollectorProxy, implements RequestHandlerInterface Primary application entry point (VERSION = '4.15.1'). Registers routes/middleware, executes handle(), strips bodies on HEAD requests (RFC 2616), and emits responses in run().
Slim\CallableResolver final class implements AdvancedCallableResolverInterface Resolves closures, invokable objects, [class, method] arrays, and 'Class:method' strings via PSR-11 container lookup or direct instantiation (new $class($container)).
Slim\MiddlewareDispatcher class implements MiddlewareDispatcherInterface Concentric LIFO (last-in, first-out) PSR-15 middleware stack wrapping the inner RequestHandlerInterface kernel (RouteRunner) with anonymous handler frames.
Slim\ResponseEmitter class — Streams PSR-7 ResponseInterface headers (Set-Cookie multi-header safe), status line, and chunked body (4096 bytes default) to standard output.
Slim\Logger class extends Psr\Log\AbstractLogger Minimal PSR-3 logger writing stringified messages to PHP's native error_log().

Slim\Factory\Psr17\ServerRequestCreator class implements ServerRequestCreatorInterface Invokes a vendor creator object/class and static/instance method via Closure::fromCallable() to build a ServerRequestInterface from globals.
Slim\Factory\Psr17\SlimHttpServerRequestCreator class implements ServerRequestCreatorInterface Decorator wrapping an inner ServerRequestCreatorInterface with Slim\Http\ServerRequest (slim/http).
Slim\Factory\Psr17\SlimPsr17Factory class extends Psr17Factory slim/psr7 (Slim\Psr7\Factory\ResponseFactory, StreamFactory, ServerRequestFactory::createFromGlobals).

packageSlim\Routing#

Route Registration, Groups, URL Generation, FastRoute Dispatch & Execution — Detailed in 03. Routing Subsystem.

The Slim\Routing namespace comprises 11 classes that manage route definitions, nested route groups, URL/path generation (RouteParser), FastRoute regex compilation and caching, request attribute enrichment (RouteContext), and per-route middleware execution:

Symbol Kind Implements / Extends Summary
Slim\Routing\RouteCollectorProxy class implements RouteCollectorProxyInterface Fluent routing DSL (get(), post(), put(), delete(), options(), patch(), any(), map(), group(), redirect()) inherited by Slim\App and passed into group callbacks.
Slim\Routing\RouteCollector class implements RouteCollectorInterface Central registry of RouteInterface and RouteGroupInterface instances, default invocation strategy, base path, and optional FastRoute cache file.
Slim\Routing\Route class implements RouteInterface, RequestHandlerInterface Represents a single HTTP route with its own mini MiddlewareDispatcher, route arguments, invocation strategy, and group middleware chain.
Slim\Routing\RouteGroup class implements RouteGroupInterface Encapsulates a shared URI prefix pattern and group-level middlewares applied to all nested routes.
Slim\Routing\RouteContext final class — Value object extracted from ServerRequestInterface via RouteContext::fromRequest($request) providing typed access to Route, RouteParser, RoutingResults, and basePath.
Slim\Routing\RouteParser class implements RouteParserInterface Reverse URL generator computing relativeUrlFor(), urlFor(), and fullUrlFor() from named routes, placeholders, and query parameters.
Slim\Routing\RouteResolver class implements RouteResolverInterface Bridges RouteCollectorInterface and DispatcherInterface to produce RoutingResults and look up matched RouteInterface objects.
Slim\Routing\RouteRunner class implements RequestHandlerInterface Innermost kernel of Slim\App's middleware stack; ensures routing has run (if RoutingMiddleware was omitted), populates RouteContext::ROUTE, and delegates to Route::run().
Slim\Routing\Dispatcher class implements DispatcherInterface Adapter around FastRoute's simpleDispatcher / cachedDispatcher returning RoutingResults and allowed HTTP methods.
Slim\Routing\FastRouteDispatcher class extends FastRoute\Dispatcher\GroupCountBased Custom FastRoute dispatcher adding transparent HEAD -> GET fallback and deduplicated allowed-method inspection.
Slim\Routing\RoutingResults class — Immutable dispatch outcome holding status (NOT_FOUND = 0, FOUND = 1, METHOD_NOT_ALLOWED = 2), route identifier (routeX), URL-decoded arguments, and allowed methods.

packageSlim\Middleware#

Built-in PSR-15 Server Middlewares — Detailed in 04. Built-in PSR-15 Middlewares.

The Slim\Middleware namespace provides 6 production-ready PSR-15 (Psr\Http\Server\MiddlewareInterface) implementations for routing, structured exception handling, request body deserialization, HTTP method tunneling, output buffering, and Content-Length calculation:

Symbol Kind Implements Summary
Slim\Middleware\RoutingMiddleware class MiddlewareInterface Executes route matching before downstream middlewares run, attaches route, routeParser, and routingResults request attributes, or throws HttpNotFoundException (404) / HttpMethodNotAllowedException (405).
Slim\Middleware\ErrorMiddleware class MiddlewareInterface Outermost try / catch (Throwable) boundary that maps exceptions to custom or default ErrorHandlerInterface instances (with optional subclass matching).
Slim\Middleware\BodyParsingMiddleware class MiddlewareInterface Parses application/json, application/x-www-form-urlencoded, and application/xml (text/xml) request streams into $request->getParsedBody(), with extensible registerBodyParser().
Slim\Middleware\ContentLengthMiddleware class MiddlewareInterface Measures $response->getBody()->getSize() after downstream handling and injects the Content-Length header if not already set.
Slim\Middleware\MethodOverrideMiddleware class MiddlewareInterface Rewrites the HTTP method using X-Http-Method-Override header or _METHOD parsed body parameter on POST requests.
Slim\Middleware\OutputBufferingMiddleware class MiddlewareInterface Captures stray echo / print output via ob_start() and either APPENDs or PREPENDs it to the PSR-7 response stream.
