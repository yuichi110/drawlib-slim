# Slim 4 User Guide Source (`docs_src/`)

Bilingual (English & Japanese) source for the **Slim Framework v4.15.3 User Guide** (`type = "site"`), compiled into `docs/`.

## Building & Serving

```bash
# Build HTML site into ../docs/ (preserving sub-portals and CNAME)
./build_html.sh

# Preview locally
./serve.sh
```
